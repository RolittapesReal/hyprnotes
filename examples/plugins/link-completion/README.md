# Link Completion

Type `[[` in a note and a popup lists your notes, filtered by what you type next. Choosing one inserts `Name]]`. When two notes share the same name the folder is included (`work/plan]]`) so the link resolves to the note you picked.

Permissions: `editor.complete` (show completion items), `notes.read` (list your notes), `notes.index` (ask the index whether a name is ambiguous). No network, nothing is changed except the text you choose to insert.
